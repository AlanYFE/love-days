# 小铃：现有香港 systemd 服务接入

本方案复用现有 `whale-dsh.service`、DSH `0.2.1-rc.4`、
`/home/ubuntu/.dsh-whale` 与 `https://whale.fefyjoey.xyz`。
不要重新运行本目录旧的 Docker 安装流程，也不要修改腾讯云原版 DSH。

## 网站端先行

日本网站先备份 `data`、`.env`、当前 Git 提交及旧容器镜像，再部署本分支。
`.env` 中配置随机 `WHALE_API_TOKEN`（至少 32 字符），重建 `app` 即可，
不用重建或重启网站 Caddy。升级自动创建读帖队列表。
登录网站，选择日历日期，在当天记录内点击「让小铃看看这一天」。
独立服务令牌不能登录成人类用户，也不能修改帖子。

先验证匿名不能读消息、错误令牌不能读帖子，再用有效令牌读取一条帖子。
验证时只输出状态和数量，不输出真实内容或令牌。

## 香港端随后接入

本目录作为 `dsh-lovedays-whale` bundle 安装进 `.dsh-whale` 的 `web` profile。
安装前停止 `whale-dsh.service` 并备份整个 `.dsh-whale`；安装失败或
持续启动检查失败时恢复该备份。当前 B 站凭据位于 `.bili-ai`，不要移动或覆盖。

以权限 600 的环境文件保存 `LOVEDAYS_URL=https://fefyjoey.xyz` 和
与日本网站一致的 `WHALE_API_TOKEN`，通过 systemd 的 `EnvironmentFile`
加载到 `whale-dsh.service`。不把密钥写进仓库、前端或聊天。
给命令执行子进程提供凭据需要在实际 DSH 权限环境中验证，不能只根据插件激活判断成功。

桥接每 15 秒领取一个被邀请的帖子。DSH 在家庭读帖会话中接收正文、全部文字留言、表情名称和每张照片的 JPEG 预览。实况照片使用静态画面。会话 ID 保存在 `$DSH_HOME/lovedays-work/day-reader-session`。读帖会话须使用支持图片的 DeepSeek Flash 模型，首次使用可能需要在 DSH 中批准写回复文件和运行 CLI 的权限。

每次读帖都加载运行用户的 `~/.bili-ai/persona.md`，可用 `LOVEDAYS_PERSONA_FILE` 指向其他人设文件。安装前用运行该服务的用户确认文件存在且可读。历史 B 站日记不会自动注入家庭会话。

## 验收

1. 用测试日期发布两篇帖子。一篇只放照片，在另一篇写正文并添加一条评论。图片挑一个正文和文件名猜不到的细节。
2. 点击「让小铃看看这一天」。关闭页面再打开，检查两篇原帖下各有一条「小铃 · AI」留言，内容分别对应照片和文字评论。页面约每 30 秒更新。
3. 换账号再次打开该日。已回复的帖子不能再生成第二条留言；同日新增帖子后可再次点击，只补读新帖。
4. 图片下载或 DSH 投递失败时可重试。已领取但十分钟没有写回也可手动重试。旧投递不能覆盖新投递的结果。长时间停在排队状态时，检查香港服务是否启用本版本插件，以及两端令牌和实际网站域名是否一致。

日本网站与香港插件需要使用同一个分支版本。完整验收需要在真实 DSH 环境观察模型看图、工具审批和评论写回。
