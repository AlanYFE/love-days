# Love Days 小鲸鱼：待部署版本

香港运行 DSH Web、B 站插件和 Love Days 消息桥；日本继续运行现有网站。
本目录不包含任何真实 API Key、B 站 Cookie、网站服务令牌或 SSH 凭据。

当前代码准备了文字帖子读取、共享聊天页面和 DSH 消息投递。真实香港服务器部署、
DSH 版本兼容性、B 站登录/浏览、两人真实聊天链路需要拿到服务器访问后实测。
不能把本目录或测试通过理解为服务已经上线。

## 接入范围

- `GET /api/whale/agent/entries`：按需分页读取帖子正文、作者、标签、最近 20 条文字评论和媒体数量。
  可传 `day`、`before`、`limit`（1–20）；不提供媒体文件、文件路径、EXIF、账号密码或会话。
- `/whale`：沿用网站登录。双方共享最近 100 条聊天；页面不加载第三方脚本。
- 服务令牌只访问 `/api/whale/agent/*`，不能登录成人类用户，也不能使用原有发帖、评论、删除和导出接口。
- AI 只能在独立聊天表中回复人类消息，每条消息最多一个回复；不创建第三个人类账号。
- 每人每小时最多发送 30 条消息，未回复队列最多 20 条。前端重试使用相同 client_id 防重复。
- DSH 桥每 15 秒检查队列；没有消息时不调用模型。每条未回复消息每天最多投递两次，间隔至少 15 分钟。
  这只限制桥接重试，不是模型费用的硬上限，B 站定时活动另算。
- 小鲸鱼读取的帖子和聊天会提供给配置的模型服务。当前不做照片理解或批量历史导入。
- B 站公共分享、评论监听和私信监听初始关闭。关闭开关和提示词不是强制网络隔离；
  当前 DSH 会话可运行命令，不能声称具备防止任何恶意提示或外传的技术保证。

## 部署前

确认香港机当前资源、Docker/Compose、3088 端口及现有 Hermes 状态。
本服务限制为 1 CPU / 1.5GB；这只是初始资源上限，需要观察实际占用。
不挂载宿主机目录、Docker socket、SSH 密钥或 Love Days 数据库。

在日本机先备份现有网站。在网站项目 `.env` 中加入随机 `WHALE_API_TOKEN`（至少 32 字符），
保留 DOMAIN 和已有配置。可以用 `python3 -c 'import secrets; print(secrets.token_urlsafe(48))'`
在自己的终端生成；不要把令牌发到聊天、提交 Git 或放入 URL。
将同一个令牌通过 SSH 安全写入香港本目录的 `.env`，设为 `chmod 600 .env`。

日本站点需要先部署本分支的 `app/whale.py`、路由、静态文件和 compose 环境配置：

```sh
sudo sh scripts/backup.sh
# 拉取并切换到经过检查的这次代码版本，确认 diff 后再运行：
sudo docker compose up -d --build
```

升级自动创建 `whale_messages` 表，不改写原有用户和帖子。网站 `/whale` 页面需要登录。
若只部署香港容器而没有更新日本网站，桥会遇到 404，不能读取帖子或聊天。

## 香港运行

在香港服务器这个 `deploy/whale` 目录执行：

```sh
docker compose build
docker compose up -d
docker compose ps
docker compose logs --tail=80 whale
```

容器以非 root 用户运行，持久化 DSH 会话、模型设置、日记和 B 站登录信息。
DSH 固定 `0.2.1-rc.4`，B 站插件固定提交 `8b0009f8ce2ebdc421afcb2e727b19ac18912ec6`。
当前构建尚未在 Docker 环境运行；如果固定版本或宿主 API 不兼容，先停服务排查，不要静默升级所有依赖。

管理端口只绑定宿主机 `127.0.0.1:3088`。从自己的电脑建立 SSH 隧道：

```sh
ssh -N -L 3088:127.0.0.1:3088 <香港服务器SSH用户>@43.132.237.254
```

按启动日志提供的带登录令牌地址进入管理界面；将端口改为本地转发的 3088，保留令牌。
完整启动 URL 属于登录凭据，不发到公开位置。不要打开腾讯云公网 3088 端口。
在 DSH 设置中填入 DeepSeek API Key，在“养鱼”设置中扫码登录 B 站。
不要在服务器日志或聊天中粘贴 Key/Cookie。单纯浏览不需要启用 B 站发言或私信。

在网站客厅发送一条测试消息后，确认 DSH 的 `lovedays-work` 会话已创建；
检查会话的命令执行权限是否允许容器内 CLI 运行。默认审批策略可能使无人值守回复停在等待审批，
须在检查容器挂载和工具范围后配置会话权限。桥不会替你放开宿主机权限。

## 验收与维护

1. 先检查匿名和错误令牌不能读取帖子；令牌不能使用人类发帖/删除接口。
2. 从你和 Joey 的两个账号分别在 `/whale` 发消息，确认作者、共享可见和鲸鱼身份回复。
3. 要求鲸鱼引用一条实际帖子，检查日期/内容；再测试一个 B 站视频，确认没有公开发言。
4. 重启容器，确认会话、Cookie 和日记仍在；重复投递同一回复不得生成两条。
5. 观察进程内存、日志和模型账单，再决定是否提高自主活动频率。

`docker compose stop` 暂停；`docker compose down` 移除容器但保留卷。
不要运行 `down -v`，它会删除记忆和登录状态。香港 `whale_home` 卷和日本网站数据需分别备份；
备份含凭据和私密聊天，按网站私有数据保存。更换服务令牌后重建两端服务使其生效。

本地检查：`PYTHONPATH=. python -m pytest tests -q`、
`node --test tests/*.test.mjs deploy/whale/tests/*.test.mjs`、`sh -n deploy/whale/start.sh`。
